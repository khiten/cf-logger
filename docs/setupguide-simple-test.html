📁 cf-logger レンタルサーバー用セットアップガイド

対象: さくらのレンタルサーバー、Xserver、JETBOY、ロリポップ等 | Version: 1.0.0 | Last Updated: 2025-11-18

このガイドは、SSH/ターミナルを使わずに、ファイルマネージャーだけで cf-logger をセットアップできるノンプログラマ向けの手順です。

ℹ 対象レンタルサーバー このガイドは以下のレンタルサーバーに対応しています：
  • さくらのレンタルサーバー
  • Xserver（エックスサーバー）
  • JETBOY
  • ロリポップ！
  • その他の共有レンタルサーバー

準備

必要なもの

  • ✓ レンタルサーバーのコントロールパネル（管理画面）にログインできること
  • ✓ ファイルマネージャー または FTP クライアント（FileZilla 等）
  • ✓ テキストエディタ（Windows: メモ帳、Mac: TextEdit 等）
  • ✓ Webブラウザ

PHP バージョン確認

レンタルサーバーのコントロールパネルで PHP バージョンを確認してください。

  • さくらのレンタルサーバー: コントロールパネル → 環境設定 → PHP設定
  • Xserver: サーバーパネル → PHPバージョン設定
  • ロリポップ： ユーザー専用ページ → サーバー設定 → PHPバージョン
✓ PHP 7.0以上であれば対応可能です。

ファイルダウンロード

ステップ1: cf-logger をダウンロード

  1. Web ブラウザで以下にアクセス:
    https://github.com/khiten/cf-logger
  2. 緑色の「Code」ボタンをクリック
  3. 「Download ZIP」をクリック
  4. ZIP ファイルがダウンロードされます（ファイル名: cf-logger-main.zip など）

※ ダウンロード完了後、ZIP ファイルを右クリック → 「すべて展開」で解凍してください（Windows）。Mac の場合は自動解凍されます。

ステップ2: フォルダ構成を確認

解凍後、以下のような構成になっていることを確認：

cf-logger-main/  (または cf-logger/)
├── config.php
├── cf-logger.php
├── README.md
├── src/
│   └── Logger.php
├── languages/
│   └── ja.php
└── logs/  (この時点では無いかもしれません)

ファイルアップロード

ファイルマネージャーを使用する場合

ステップ1: ファイルマネージャーを開く

  1. レンタルサーバーのコントロールパネルにログイン
  2. ファイルマネージャーを開く
    • さくらのレンタルサーバー: コントロールパネル → ファイルマネージャー
    • Xserver: サーバーパネル → ファイルマネージャー

ステップ2: Web 公開フォルダに移動

通常、以下のフォルダが Web 公開フォルダです：

  • さくらのレンタルサーバー: www/ または public_html/
  • Xserver: public_html/
  • ロリポップ: public_html/

このフォルダを開いてください。

ステップ3: cf-logger フォルダを新規作成

  1. ファイルマネージャー画面で「新規フォルダ作成」をクリック
  2. フォルダ名: cf-logger と入力
  3. 作成ボタンをクリック

※ ご自身のサイトトップ直下に cf-logger というフォルダが作成されます。

ステップ4: cf-logger フォルダ内にファイルをアップロード

  1. 先ほど作成した cf-logger フォルダをダブルクリックで開く
  2. ファイルマネージャーの「アップロード」ボタンをクリック
  3. ダウンロードした ZIP から解凍した以下のファイルを選択してアップロード:
    • config.php
    • cf-logger.php
    • README.md
    • src/ フォルダ全体
    • languages/ フォルダ全体

※ 複数ファイルは一度に選択してアップロードできます。Ctrl キーを押しながらクリックで複数選択。

ステップ5: logs フォルダを作成

  1. cf-logger フォルダ内で「新規フォルダ作成」をクリック
  2. フォルダ名: logs と入力
  3. 作成ボタンをクリック

FTP クライアント（FileZilla 等）を使用する場合

FTP 接続情報を確認

レンタルサーバーのコントロールパネルから FTP ログイン情報を確認：

  • FTP サーバー（ホスト名）
  • FTP ユーザー名
  • FTP パスワード
  • FTP ポート（通常 21）

FileZilla で接続

  1. FileZilla を起動
  2. メニュー: ファイル → サイトマネージャー
  3. 「新しいサイト」をクリック
  4. 以下を入力:
    • プロトコル: FTP
    • ホスト: 上記で確認した FTP サーバー
    • ユーザー: 上記で確認した FTP ユーザー名
    • パスワード: 上記で確認した FTP パスワード
  5. 「接続」をクリック

接続後、Web 公開フォルダ（public_html/ 等）に cf-logger フォルダをアップロードします。

パーミッション設定

logs フォルダのパーミッション設定

ファイルマネージャーでの設定

  1. cf-logger/logs フォルダを右クリック
  2. 「属性」または「パーミッション」を選択
  3. 以下の権限を設定:
    • オーナー（所有者）: 読み取り、書き込み、実行 ✓
    • グループ: 読み取り、実行 ✓
    • その他: 読み取り、実行 ✓
  4. 「OK」または「適用」をクリック

※ 数値で表すと 755 です。レンタルサーバーによっては自動で設定されることもあります。

設定ファイル編集

ステップ1: ファイルマネージャーで config.php を編集

  1. ファイルマネージャーで cf-logger/config.php を選択
  2. 右クリック → 「編集」を選択（または「ダウンロード」してテキストエディタで開く）
  3. 以下の設定を確認: 
    define('LOG_FORMAT_TYPE', 'simple');
define('LOG_DATE_FORMAT', 'Y/m/d H:i:s');
define('LOG_STATUS_ENABLED', true);
define('LOG_DIRECTORY', 'logs');
define('LOG_FILE_TYPE', 'rotate');
define('LOG_DIRECTORY_MODE', 'yeardir');
define('LOG_LANGUAGE', 'ja');
  4. 必要に応じて変更（初心者は「デフォルト値」のままでOK）
  5. 保存

※ デフォルト値は一般的な設定で、ほとんどの環境で動作します。

ノンプログラマ向け: 設定値の簡単説明

設定名 意味 デフォルト値
LOG_FORMAT_TYPE ログをどの形式で保存するか simple（シンプル形式）
LOG_DATE_FORMAT 日付の表記方法 Y/m/d H:i:s（例: 2025/11/18 17:30:45）
LOG_STATUS_ENABLED HTTP ステータス（200, 404等）をログに記録するか true（記録する）
LOG_DIRECTORY ログを保存するフォルダ logs
LOG_FILE_TYPE ログを日ごとに分割するか rotate（日ごとに分割）
LOG_LANGUAGE エラーメッセージの言語 ja（日本語）

動作確認

ステップ1: テストページを作成

  1. サイトの header.php または template.php などの共通ファイルを開く
  2. ファイルの最初に以下を追加: 
    <?php
require_once __DIR__ . '/cf-logger/cf-logger.php';
?>
  3. 保存

ステップ2: Web ブラウザでサイトにアクセス

  1. ご自身のサイトをブラウザで開く
  2. ページが正常に表示されることを確認

ステップ3: ログファイルを確認

  1. ファイルマネージャーで cf-logger/logs/ フォルダを開く
  2. 日付ごとのフォルダ（例: 2025/11/）が作成されているか確認
  3. その中に cf_access_20251118.log のようなファイルがあるか確認
  4. ファイルをダウンロードして内容を確認 
    2025/11/18 17:30:45 127.0.0.1 PC Chrome/142.0.0.0 GET /index.php 200
✓ ログが記録されていれば成功です！

WordPress への組込

WordPress がインストールされている場合

ステップ1: テーマの functions.php を編集

  1. ファイルマネージャーで wp-content/themes/ご使用のテーマ名/functions.php を開く
  2. ファイルの最初（一番上）に以下を追加: 
    <?php
require_once __DIR__ . '/../../cf-logger/cf-logger.php';
?>
  3. 保存

ステップ2: WordPress サイトにアクセスして確認

  1. WordPress ブログにアクセス
  2. ページが正常に表示されることを確認
  3. ファイルマネージャーで cf-logger/logs/ を確認
  4. ログが記録されているか確認

トラブルシューティング

【問題】ログが記録されない

⚠ よくある原因と対処法
原因 確認方法 対処法
logs フォルダが存在しない ファイルマネージャーで cf-logger/ を確認 上記「パーミッション設定」の「logs フォルダを作成」を実行
logs フォルダの パーミッションが間違っている ファイルマネージャーで右クリック → 属性 「書き込み」権限を有効（チェック）にする
ファイルアップロードが不完全 ファイルマネージャーで cf-logger/ 内のファイル一覧 上記「ファイルアップロード」を再度実行

【問題】サイトが真っ白になった（エラー画面）

⚠ 対処法
  1. ファイルマネージャーで編集したファイル（header.php や functions.php）を開く
  2. 追加した行を確認: 
    <?php
require_once __DIR__ . '/cf-logger/cf-logger.php';
?>
    この行が正しく入っているか確認
  3. パスが間違っていないか確認（フォルダ構造に合わせて `../` の数を調整）
  4. 構文が正しいか確認（`` が揃っているか）
  5. 修正して保存
  6. ブラウザをリロード（F5 キーを押す）
ℹ 最後の手段 追加した行を削除すれば、サイトは元に戻ります。その上で、セットアップを最初からやり直してください。

【問題】ログファイルが表示されない

  1. ブラウザのキャッシュをクリア（Ctrl+Shift+Delete キー、またはブラウザ設定から）
  2. ファイルマネージャーをリロード（ブラウザをリロード）
  3. ログが作成されるまで 1〜2 分待つ
  4. それでも表示されない場合は、エラーログを確認:
    • レンタルサーバーのコントロールパネル → ログ → エラーログ
    • PHP エラーが出ていないか確認
